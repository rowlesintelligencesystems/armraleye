## PART A — MANDATORY MANUAL / PRODUCT STRUCTURE (v1.1)

Every manual and product **must** contain the following elements in this order (or a clear equivalent). Missing any item means the document is not yet to standard.

### 1. Hero Graphics
- Accurate visual depiction of the product itself
- High-resolution, on-brand, no generic stock
- Should instantly communicate what the product does or is

### 2. Company Logo + S'Cara Logo
- ARMR ALEYE primary mark (winged-S + halo)  
- S'Cara wordmark / logo lockup
- Both present on cover and available for interior use

### 3. S'Cara Avatar Image
- Locked approved S'Cara character render
- Used as the consistent human / persona face of the product family
- Never substituted with unofficial or dark variants

### 4. Table of Contents
- Clear, numbered, complete
- Allows an operator to jump directly to any major section

### 5. Introduction
- Purpose of the document
- Who it is for
- How to use it
- What this is / What this is not
- Doctrine sequence treated as operating architecture

### 6. Body (Deep Research)
- Core model, definitions, methods, frameworks
- Evidence-informed or research-backed principles where applicable
- Practical depth (not brochure-thin)
- Claims boundary respected throughout

### 7. Support Systems Intelligent Integration
- Explicit mapping to other ARMR systems and products:
  - PIE / PEIE / PPI / Trend / CIE / AIIE
  - S'Cara, Hand of Hamsa, Milestone Payment Gate, Architecture Manuals
  - Subscription plans and credit logic
- How this product supports or is supported by the wider ecosystem

### 8. Info Graphics
- Visual diagrams, process flows, comparison tables, phase cards, score breakdowns
- Must be custom and on-brand (navy / gold / cyan)
- Prefer clarity over decoration

### 9. Outro
- Summary of key points
- Clear next actions for the operator
- Reference to related locked documents

### 10. Outcomes
- What successful use of this product looks like
- Measurable or observable results (educational framing only — no guaranteed income/ROI claims)
- How outcomes connect back to doctrine and claims boundary

### 11. Branding Colors + Custom Graphics Wrap
- Full visual system applied:
  - Deep navy backgrounds
  - Gold headers and accents
  - Ivory body text
  - Cyan highlights and links
- Custom graphics (logo, S'Cara, Hamsa, process diagrams) throughout
- Consistent footer with SKU and page numbers
- Cover and closing pages carry the full brand lockup

## PART C — PATTERN LOG (Condensed)

**Structure spine that works:**  
Hero → Logos → S'Cara Avatar → TOC → Intro → Deep Body → System Integration → Infographics → Outro → Outcomes → Brand Wrap

**Visual non-negotiables:**  
Navy ground · Gold hierarchy · Cyan emphasis · Locked S'Cara + Hamsa + Logo only

**Integration non-negotiables:**  
Always show how the product connects to PIE/PEIE, S'Cara, Milestone Gate, Architecture Manuals, and the live subscription surface.

**Lock sequence:**  
PDF → Drive link → Repo Markdown → MSOT (if needed) → Running File → Document contains its own Drive link

**Anti-patterns:**  
Missing TOC · Missing S'Cara avatar · Missing system integration · Missing subscription links · Thin brochure body · Unofficial imagery · Forgotten claims boundary
