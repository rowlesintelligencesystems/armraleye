# S'Cara — Buyer Checklist

**Product:** S'Cara (ARMR ALEYE Product #1)  
**Version:** 1.0  
**Date:** 2026-08-04  
**Use:** Print or copy into your vault. Check items as you complete them.

---

## What this checklist is for

S'Cara helps you turn a **framework or method you already understand** into **action-ready tools** (guides, checklists, planners, workflows) that customers can use immediately.

**Rules of the road**
- You supply the **execution layer** — not a copy of someone else’s protected text.
- Stay practical: templates, steps, and tools people can run.
- Finish one companion product before starting five variations.

---

## Phase A — Clarify (before you build)

- [ ] **A1.** Name the source framework or method in one line (your own words).
- [ ] **A2.** Write the audience in one line (who buys this companion?).
- [ ] **A3.** Write the problem in one line (what they can’t apply today).
- [ ] **A4.** Write the desired outcome in one line (what “success” looks like after using your tools).
- [ ] **A5.** Confirm you will **not** paste or republish copyrighted chapters, course modules, or proprietary text from the source.

**Exit:** *“For [audience], this companion helps them [outcome] when they struggle with [problem].”*

---

## Phase B — Choose your templates

- [ ] **B1.** Select **Guide**
- [ ] **B2.** Select **Checklist**
- [ ] **B3.** Select **Listing**
- [ ] **B4.** Select **Bonus** (optional)
- [ ] **B5.** Lock the set for this build

**Recommended MVP:** Guide + Checklist + Listing

---

## Phase C — Build the execution layer only

- [ ] **C1.** Outline the Guide in sections (what to do, in order)
- [ ] **C2.** Write Checklist items as **actions**
- [ ] **C3.** Draft Listing: title, headline, 4–6 bullets, CTA
- [ ] **C4.** If Bonus: one page only
- [ ] **C5.** Remove anything that only repeats the original framework’s wording
- [ ] **C6.** Read once as a beginner in your audience — fix stuck points

**Exit:** A stranger could follow the Checklist without you in the room.

---

## Phase D — Protect and store

- [ ] **D1.** Folder tree (Guide / Checklist / Listing / Bonus / Exports)
- [ ] **D2.** Export shippable package (PDF and/or Markdown/ZIP)
- [ ] **D3.** Version + date on the package
- [ ] **D4.** Optional: checksum of final ZIP
- [ ] **D5.** Optional: NDA for collaborators

---

## Phase E — Package for sale

- [ ] **E1.** Choose: Core / **Bundle (MVP)** / Bundle + upsell
- [ ] **E2.** Set price (ref: Core ~$47 · Bundle ~$77 · Upsell ~$27 · Niche ~$37)
- [ ] **E3.** “What’s included” matches real files
- [ ] **E4.** Guarantee line you can stand behind
- [ ] **E5.** Cover image (optional)

---

## Phase F — Deploy

- [ ] **F1.** Upload files to store or delivery method
- [ ] **F2.** Paste listing title, description, bullets, CTA
- [ ] **F3.** Inventory > 0 if you intend to sell
- [ ] **F4.** Test order / open files as customer
- [ ] **F5.** Fix breaks
- [ ] **F6.** Publish / Active

---

## Phase G — Multiply (after first ship)

- [ ] **G1.** List 3 variation ideas
- [ ] **G2.** Pick **one** next variation only
- [ ] **G3.** Re-run from Phase A for that variation
- [ ] **G4.** Optional: affiliate path
- [ ] **G5.** Optional: monthly update if subscription

---

## Quick spine
